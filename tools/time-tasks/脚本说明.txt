脚本名称：time_tasks
主要功能：多设备定时关机/重启任务管理器
详细说明：
  - 带 tkinter GUI 界面，支持图形化配置
  - 支持单台或多台设备批量操作（设备 SN 以英文逗号分隔）
  - 可配置每周执行计划（选择星期几执行）
  - 支持定时关机、定时重启等任务类型
  - 通过 HTTP API 调用控制设备（针对京东/JD 平台）
  - 支持多种环境：测试环境、正式环境、京东现场私有化环境
  - 配置自动保存到 config.json，日志记录到 log.txt
版本：V1.4（2024-11-14）
入口文件：time_task-JD-shutdown-restart - 副本.py
