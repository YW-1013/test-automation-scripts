# 老化稳定性测试 aging-test

> Android 设备**出厂前老化测试**脚本：用 uiautomator2 循环执行各功能模块，长时间连续运行以暴露稳定性问题（崩溃、卡死、内存泄漏、功能失效等）。

---

## 说明

- **循环压测**：uiautomator2 控制 Android 设备，循环遍历各功能模块（如白板 blackboard 的各项操作），持续运行数小时到数天。
- **统一异常捕获**：通过装饰器统一捕获每个测试步骤的异常并记录错误日志，便于长时运行后定位是哪一步、第几次出的问题。
- **并行执行**：多进程 / 多线程并行执行测试任务，提高老化覆盖强度。
- **用途**：设备出厂前的老化验证，确认长时间运行的稳定性。

入口文件：`aging_blackboard.py`

## 技术栈

`Python 3` · `uiautomator2` / `adb` · 多进程 / 多线程 · 装饰器统一异常处理
