1、安装三方库包：
  下载后请使用pip安装：requirements.txt  文件中的包
  命令：
  pip install -r requirement.txt

  或者单独的云pip安装对应的包
  命令：
  pip install openpyxl
  pip install PyMySQL
  pip install requests
  pip install jsonpath

2、运行
   test_run.py
	这是运行文件，直接运行即可

3、用例编写
   在data目录下有用例的xlsx文件，按照其编写用例即可运行
